# ABYSS / 深渊档案

由滚动驱动的沉浸式深海科考网站，使用原生 HTML、CSS、SVG、Canvas 和 JavaScript 构建，无第三方运行依赖。

## 本地运行

```bash
python3 -m http.server 4173
```

访问 `http://localhost:4173`。网站包含实时遥测、四层海域、声呐扫描、信号解析、物种日志、本地进度保存、响应式布局和减少动态效果支持。

## 阅读与娱乐

科学阅读室包含 18 条档案：8 条海洋科学、6 条生物介绍和 4 条探索历史。可按类别筛选并展开补充笔记。深海影院收录 4 部电影的原创简介与科学对照，明确标注虚构设定；所有电影视觉均由 CSS 绘制。

`content.js` 保存新增档案内容，`script.js` 处理下潜交互。遥测深度按海域章节位置计算，不受后续阅读区域长度影响。资料入口与本轮核验限制见 [SOURCES.md](SOURCES.md)。
